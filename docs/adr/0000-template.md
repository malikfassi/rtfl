# ADR 0000 — Modèle

- **Statut** : modèle
- **Date** : aaaa-mm-jj

## Contexte

Ce qui pousse à décider. Deux ou trois phrases, factuelles.

## Décision

Ce qui est décidé, à l'infinitif ou au présent. Pas d'options laissées ouvertes.

## Conséquences

Ce que ça impose, ce que ça coûte, ce que ça empêche. Les pièges à connaître.

---

Un ADR fait 25 lignes maximum. Il enregistre une décision **prise**, pas une discussion : si le choix n'est pas encore fait, la question se pose d'abord (au propriétaire du produit), l'ADR se remplit ensuite. Une décision acceptée ne se re-débat pas sans un nouvel élément ; pour la changer, on crée un ADR qui remplace le précédent.
